# Pause Choice signed database updates

This public repository contains operator-reviewed, cumulative PCAGS1 database release assets for Pause Choice.

The Android app verifies every database using its pinned RSA public key. GitHub metadata is not an authenticity authority. Private signing keys, user data, browsing history, and Analyzer evidence are never uploaded here.

Download channel: GitHub Releases, tags `ags-VERSION`, asset `rules-VERSION.ags`.

A database release updates the AGS layer; the built-in protection database and personal settings remain separate.
